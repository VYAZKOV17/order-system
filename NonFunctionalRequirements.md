# Производительность
95% запросов GET /orders/{orderId} должны обрабатываться не более чем за 500 мс.
# Доступность
Сервис Order Service должен обеспечивать доступность
не менее 99,9% в течение календарного месяца,
за исключением согласованных окон технического обслуживания.
# Надёжность
Система не должна создавать более одного заказа
при повторной отправке одного запроса с одинаковым
Idempotency-Key.
