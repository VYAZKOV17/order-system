# Система онлайн заказа товаров

## О проекте

Учебный проект по системному анализу процесса оформления
и обработки интернет-заказа.

Необходимо автоматизировать процесс обработки заказа:
проверку наличия товаров, резервирование, оплату и передачу
заказа на сборку.

## Цель

Спроектировать целевой бизнес-процесс и системное
взаимодействие компонентов.
В рамках проекта рассматриваются:

- создание заказа;
- проверка наличия;
- резервирование товара;
- оплата;
- отмена заказа;
- передача на сборку;
- уведомление клиента.
